# Security policy

Do not include credentials or exploit details in public issues or discussions.
If GitHub private vulnerability reporting is enabled for this repository, use
its **Report a vulnerability** page. If that private route is unavailable, ask
the repository owner for a private reporting channel before sharing details.

The local security task scans Git history with Gitleaks and audits GitHub Actions
with actionlint and zizmor. These checks do not replace careful review of
dependencies and application changes.
