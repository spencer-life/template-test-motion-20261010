# Design work

Keep the product scope in `PRODUCT.md` and the visual decisions in
`DESIGN.md`. Preserve the current quiet, paper-and-evergreen direction unless a
change asks for a different one. Use the project-local guidance in
`.agents/skills` for web platform behavior and motion; see
[design setup](design/setup.md) for sources, revisions, and fallback guidance.

Review keyboard focus, responsive layout, contrast, form errors, and reduced
motion when changing the interface. The starter uses native controls and has no
component or animation library.
